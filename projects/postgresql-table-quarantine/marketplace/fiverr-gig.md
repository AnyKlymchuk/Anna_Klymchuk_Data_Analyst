# Fiverr Gig

## Gig Title
I will clean up and optimize your PostgreSQL database safely

## Short Description
I will analyze your PostgreSQL database, identify unused or risky tables, and create a safe cleanup workflow with dependency checks, quarantine, rollback, and audit logging.

## Full Description
Is your PostgreSQL database full of old tables, test copies, snapshots, or duplicated datasets, but you are afraid to delete them because they may still be connected to reports or scripts?

I can help you clean up the database safely.

My approach is not to delete tables blindly. I first analyze activity and dependencies, then create a reversible quarantine process before any final deletion.

### I can help with
- PostgreSQL table inventory and size analysis
- read/write activity checks
- unused table detection
- dependency checks for views and reporting workflows
- SQL cleanup scripts
- quarantine schema setup
- audit logging
- rollback / restore procedure
- safe DROP workflow without CASCADE
- documentation of the cleanup process

### Good fit for
- analytics databases
- Power BI / BI reporting environments
- PostgreSQL staging databases
- ETL pipelines
- databases with many legacy or test tables

### Deliverables
You receive SQL scripts, a clear cleanup plan, a list of findings, and instructions for safely restoring or deleting candidate tables.

Please contact me before ordering if the database is production-critical or has complex application dependencies.
